## Overview

**Attack on Titan** is a Japanese dark fantasy anime series adapted from the manga by *Hajime Isayama*. It is set in a world where humanity lives inside three enormous walls to protect themselves from giant man-eating humanoids known as **Titans**.

### Main Characters

- **Eren Yeager** - The main protagonist who wants to eliminate all Titans.
- *Mikasa Ackerman* - Eren's adoptive sister and a skilled soldier.
- ~~Armin Arlert~~ - Just kidding! He is Eren's best friend and a brilliant strategist.
